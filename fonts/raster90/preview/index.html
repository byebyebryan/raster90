Raster 90 bitmap font family

Approved project-owned two-cut family for the one solid 3×3 source-cell grid. This page is generated from the authoritative matrices and has no network or runtime-font dependency.

Design contract

  • Primary/display cut: dense fixed-width 0–9 plus colon, with the reviewed clean-chamfer selection and retained square construction control; both use 26×32 digit boxes and a 10×32 colon box.
  • Secondary/text cut: complete 5×7 space, symbols, digits, uppercase, lowercase, and common punctuation vocabulary.
  • All lit source cells expand to solid 3×3 squares. No glow, gradient, antialiasing, or downloaded runtime font is used.
  • The APK packages only the secondary glyphs current WFF expressions can emit; this page intentionally shows the complete source-only surface.
